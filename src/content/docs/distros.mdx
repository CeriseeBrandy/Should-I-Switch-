# Choosing a Linux Distribution

One of the first things you'll encounter when researching Linux is the word "distribution" (or "distro"). Unlike Windows or macOS, Linux isn't a single operating system — it's a kernel that many different projects have built full operating systems around.

Choosing the wrong distribution is one of the most common sources of early frustration. This page helps you pick one that fits your actual situation.

---

## What Is a Distribution?

A Linux distribution packages the Linux kernel together with:
- A package manager (for installing software)
- Default applications and desktop environment
- System configuration tools
- An update and release schedule

Different distributions make different choices about all of these. The result is systems that share a common core but feel and behave quite differently.

---

## The Most Important Rule

<Aside type="tip" title="Start with the boring choice">
Your first Linux distribution should be the one with the most documentation, the largest community, and the most predictable behavior — not the most technically impressive or the one with the most community prestige.

You can always switch later. Starting with something well-documented means your problems will have answers you can find with a search.
</Aside>

## Distributions by Category

<Tabs>
  <TabItem label="For Beginners">

    ### Ubuntu

    Ubuntu is the most widely documented Linux distribution. Whatever problem you encounter, someone has written about it. It has broad hardware support, a large community, and a predictable release schedule.

    - **Based on:** Debian
    - **Package manager:** `apt`
    - **Release cycle:** New version every 6 months; LTS (Long Term Support) every 2 years
    - **Desktop:** GNOME by default
    - **Good for:** Beginners, developers, general use

    If you don't know what to pick, Ubuntu or one of its variants is a safe default.

    ---

    ### Linux Mint

    Linux Mint is based on Ubuntu but ships with a more traditional desktop layout that feels more familiar to Windows users. It prioritizes stability and ease of use over having the latest software.

    - **Based on:** Ubuntu (Debian underneath)
    - **Package manager:** `apt`
    - **Desktop:** Cinnamon (default), MATE, or XFCE
    - **Good for:** People switching from Windows who want a familiar layout

    ---

    ### Pop!_OS

    Pop!_OS is made by System76, a Linux hardware company. It has excellent out-of-the-box hardware support, a polished GNOME-based desktop, and ships separate ISO images for NVIDIA and AMD GPUs.

    - **Based on:** Ubuntu
    - **Package manager:** `apt`
    - **Desktop:** COSMIC (in development) / GNOME
    - **Good for:** Developers, people with NVIDIA GPUs, people who want a polished default experience

  </TabItem>

  <TabItem label="For Developers">

    ### Fedora

    Fedora is sponsored by Red Hat and sits at the leading edge of Linux innovation. It ships newer software than Ubuntu (including recent kernels and desktop tooling) and is well-regarded among developers.

    - **Based on:** Independent (RPM-based)
    - **Package manager:** `dnf`
    - **Release cycle:** New version every 6 months; each supported for ~13 months
    - **Desktop:** GNOME (default), KDE, and others via spins
    - **Good for:** Developers who want up-to-date tooling, people interested in enterprise Linux workflows

    Note: Fedora moves fast. Things occasionally break between updates.

    ---

    ### openSUSE Tumbleweed

    openSUSE Tumbleweed is a "rolling release" distribution — it continuously receives updated packages rather than shipping periodic versions. It has a strong QA process for a rolling release.

    - **Based on:** Independent (RPM-based)
    - **Package manager:** `zypper`
    - **Desktop:** KDE Plasma (default)
    - **Good for:** Developers who want the latest software with good system management tools

  </TabItem>

  <TabItem label="For Servers">

    ### Ubuntu Server LTS

    Ubuntu LTS is among the most widely used server distributions. Extensive documentation, cloud image support on all major providers, and a 5-year support window make it a practical default.

    - **Support window:** 5 years (up to 12 with extended support)
    - **Good for:** Web servers, cloud VMs, beginners to server administration

    ---

    ### Debian

    Debian prioritizes stability above all else. It moves slowly by design, which means its packages are very well-tested. Many experienced administrators prefer it for production systems.

    - **Support window:** Long-term
    - **Good for:** Stable long-running servers, administrators who prefer minimal installs

    ---

    ### Rocky Linux / AlmaLinux

    Community-maintained rebuilds of Red Hat Enterprise Linux. Binary-compatible with RHEL, which means they work with enterprise software certified for RHEL environments.

    - **Good for:** Enterprise environments, RHEL-compatible workflows, long-term stability

  </TabItem>

  <TabItem label="Advanced / Power Users">

    ### Arch Linux

    <Aside type="danger">
    Arch Linux is not recommended as a first Linux experience. It requires significant manual setup, ongoing maintenance attention, and comfort with troubleshooting.
    </Aside>

    Arch is a rolling release distribution that ships minimal by default. You build the system you want from the ground up. It has exceptional documentation (the Arch Wiki is one of the best Linux references regardless of what distribution you use).

    - **Good for:** Experienced Linux users who want full control and the latest packages

    ---

    ### NixOS

    NixOS uses a declarative configuration model — your entire system configuration is defined in a single file. This enables reproducible builds and easy rollbacks, but requires learning a new configuration language (Nix).

    - **Good for:** People interested in reproducible infrastructure, experienced Linux users, developers who want to manage system config as code

    ---

    ### Gentoo

    Gentoo compiles software from source. This gives fine-grained control over compilation flags and installed features, but means installations take significantly longer. Very rarely the right choice for most users.

  </TabItem>
</Tabs>

## Desktop Environments

Independent of which distribution you choose, you also choose (or inherit) a desktop environment — the graphical interface.

<CardGrid>
  <Card title="GNOME" icon="information">
    Modern, clean, keyboard-driven. Used by Ubuntu and Fedora by default. Has a distinctive workflow some users love and others dislike.
  </Card>

  <Card title="KDE Plasma" icon="information">
    Highly customizable, feature-rich, Windows-like layout options. Used by openSUSE and Fedora KDE spin by default. Good for users who want control over their environment.
  </Card>

  <Card title="Cinnamon" icon="information">
    Traditional desktop layout. Used by Linux Mint by default. Familiar to Windows users.
  </Card>

  <Card title="XFCE / LXDE / LXQt" icon="information">
    Lightweight desktop environments. Good for older hardware or users who want a minimal, fast desktop.
  </Card>
</CardGrid>

## Which Should You Pick?

| Your Situation | Recommendation |
|---|---|
| Complete Linux beginner | Linux Mint or Ubuntu |
| Windows user wanting familiarity | Linux Mint (Cinnamon) |
| Developer (general) | Ubuntu, Fedora, or Pop!_OS |
| NVIDIA GPU, wants easy setup | Pop!_OS |
| Interested in enterprise Linux | Fedora or Rocky Linux |
| Server / production use | Ubuntu Server LTS, Debian, or Rocky Linux |
| AI / ML workloads | Ubuntu or Pop!_OS |
| Already experienced with Linux | Arch, Fedora, or whatever suits you |
