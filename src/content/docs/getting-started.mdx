# Getting Started

This site exists to help you make an informed decision about switching to Linux — not to convince you one way or the other.

If you landed here after someone told you to "just use Linux," or after getting frustrated with Windows or macOS, this is a good place to start. Take your time.

## Where to Begin

<Steps>

1. **Read [Before You Switch](/before-you-switch/)**

   This is the most important page on the site. It lists specific situations where switching to Linux is likely to cause frustration. If any of them apply to you, read those sections carefully before doing anything else.

2. **Check your use case**

   Browse the use-case pages for your primary computer activity — gaming, development, servers, or AI/ML. Each one covers the real-world state of Linux support for that context.

3. **Check software compatibility**

   Make a list of the software you use daily. Then check the [Software Compatibility](/software-compatibility/) page to understand what has equivalents, what doesn't, and what the transition actually looks like.

4. **Explore distributions**

   If the picture looks positive for your situation, the [Distributions](/distros/) page will help you pick a starting point. Picking the wrong distribution is a common beginner mistake.

5. **Try it without committing**

   Most Linux distributions let you boot from a USB drive and try them without installing anything. This is almost always worth doing before making any changes to your system.

</Steps>

## A Note on Expectations

<Aside type="caution" title="Set realistic expectations">
Linux is not a drop-in replacement for Windows or macOS. It works differently in some fundamental ways. Some things will be better. Some things will require adjustment. A small number of things may not work at all for your specific hardware or software needs.

Going in with accurate expectations makes the difference between a successful transition and a frustrating one.
</Aside>

Common things that surprise new Linux users:

- **Software installation** works differently — most software comes from a package manager, not a website
- **File system layout** is different from Windows — there is no `C:\` drive
- **Driver handling** is mostly automatic, but can require extra steps for some hardware (notably certain Wi-Fi chips and NVIDIA GPUs)
- **Some things just work better** — particularly terminal tooling, package management, and system resource usage
- **Some things require workarounds** — particularly proprietary software, gaming anti-cheat, and hardware with poor vendor support

## What This Site Won't Do

- Tell you Linux is always better
- Pretend Windows or macOS have no advantages
- Recommend Linux to people whose workflows depend on software that doesn't exist on Linux
- Use social pressure or elitism to push you toward a decision

If Linux is the right choice for you, the facts will make that clear. If it isn't, we'd rather you know that up front.
