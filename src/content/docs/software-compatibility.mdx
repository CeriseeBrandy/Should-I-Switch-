# Software Compatibility

Before switching to Linux, make a list of every piece of software you use regularly. Then check it against this page.

This is one of the most important steps in deciding whether to switch. "I can find alternatives" is sometimes true and fine — and sometimes means months of workflow disruption. Knowing the difference matters.

---

## How to Read This Page

Each section covers a software category and its Linux situation:

- ✅ **Works natively** — official Linux version exists
- ⚠️ **Partial / alternatives exist** — no direct port, but usable replacements or workarounds
- ❌ **No viable option** — significant gap, no satisfactory workaround for most users

---

## Web Browsers

✅ **Full support.**

Firefox, Chromium, and Google Chrome all have official Linux builds. Brave, Vivaldi, and Opera also support Linux. Microsoft Edge has a Linux build.

## Office and Productivity

<Aside type="caution">
If your work involves heavy collaboration on Microsoft Office documents — particularly complex Word documents, Excel files with macros, or PowerPoint with advanced formatting — expect some friction. File format compatibility between LibreOffice and Microsoft Office is good but not perfect.
</Aside>

| App | Linux Status |
|---|---|
| Microsoft Word | ❌ No native client — web version works in browser |
| Microsoft Excel | ❌ No native client — web version works in browser |
| Microsoft PowerPoint | ❌ No native client — web version works in browser |
| LibreOffice Writer | ✅ Full native — Word-compatible formats |
| LibreOffice Calc | ✅ Full native — Excel-compatible formats |
| LibreOffice Impress | ✅ Full native — PowerPoint-compatible formats |
| Google Docs / Sheets / Slides | ✅ Web-based, works in any browser |
| Notion | ⚠️ No native app; web version works fully |
| Obsidian | ✅ Official native app |

## Creative Tools

<Aside type="danger" title="Adobe users: read this carefully">
Adobe's desktop applications — Photoshop, Illustrator, Premiere, After Effects, InDesign, Lightroom — have no native Linux versions. The open-source alternatives are real applications, but they are different tools with different workflows. Do not assume a direct replacement.
</Aside>

## VPN Clients (Corporate)

<Aside type="caution">
Corporate VPN clients are a common compatibility issue. Many enterprise VPN clients — including some Cisco AnyConnect configurations and some Palo Alto GlobalProtect deployments — have limited or no Linux support.

Check with your IT department before switching a work machine.
</Aside>

| App | Linux Status |
|---|---|
| OpenVPN | ✅ Native |
| WireGuard | ✅ Native (built into Linux kernel) |
| Cisco AnyConnect | ⚠️ Official client exists but has limitations on some distributions |
| GlobalProtect (Palo Alto) | ⚠️ Linux client available but may not support all organizational configurations |

## How to Verify Your Specific Software

1. Search for the software name + "Linux" to find official documentation or download pages
2. Check [AlternativeTo](https://alternativeto.net/) — filter by "Linux" platform — for alternatives
3. Search the software name on [WineHQ AppDB](https://appdb.winehq.org/) to see if it runs under Wine
4. Ask on [r/linux4noobs](https://www.reddit.com/r/linux4noobs/) with your specific use case
