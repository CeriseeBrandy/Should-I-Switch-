# What is Linux?

Linux is an open-source operating system kernel created in 1991 by Linus Torvalds.

Today, when people say "Linux", they usually refer to complete operating systems built around the Linux kernel, such as Fedora, Ubuntu, Debian, Linux Mint, openSUSE, or Arch Linux.

Linux powers everything from personal computers and servers to smartphones, embedded devices, and supercomputers.

## Who Created Linux?

Linux was created by **Linus Torvalds**, a computer science student from Finland.

In 1991, he started working on a personal operating system project as a hobby while studying at the University of Helsinki.

What started as a small experiment eventually became one of the most important software projects in history.

## Why Was Linux Created?

At the time, many operating systems were either expensive, proprietary, or difficult for students to experiment with.

Linus Torvalds wanted a free and flexible operating system that he could learn from and improve himself.

He shared his work publicly on the internet and invited others to contribute.

Thousands of developers joined the project over the years, helping Linux grow into the ecosystem we know today.

## Linux Is Not a Distribution

A common misconception is that Linux is a complete operating system.

Technically, Linux is only the **kernel**.

A kernel is the core component that manages communication between software and hardware.

The systems people install are called **Linux distributions** (or **distros**), which combine the Linux kernel with software, desktop environments, package managers, and tools.

Examples include:

- Fedora
- Ubuntu
- Debian
- Linux Mint
- openSUSE
- Arch Linux

## Where Is Linux Used?

Linux is used in many places:

- Personal computers
- Servers
- Cloud infrastructure
- Android smartphones
- Smart TVs
- Embedded devices
- Supercomputers

Even people who have never installed Linux often use devices powered by Linux every day.
